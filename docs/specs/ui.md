# UI

Разметка через `el()`, исходный `body` пустой кроме `script`. Тексты — [D-008](../decisions.md). Логика раунда уже лежит в ядре к моменту этих шагов. Шаги экрана идут сверху вниз. Соседний шаг не начинать.

Общие строки:

| Место | Текст |
| --- | --- |
| Заголовок документа и страницы | Быки и коровы |
| Старт | Начать игру |
| Рестарт | Новая игра |
| Поле | Попытка |
| Кнопка попытки | Проверить |
| Повтор | Эта попытка уже была |
| Пустая история | Пока нет попыток |
| Победа | Вы угадали |
| Пустые рекорды | Пока нет результатов |
| Заголовок таблицы | Рекорды |

## `feat/app-shell`

- В собранном дереве есть заголовок «Быки и коровы», кнопка «Новая игра» и секция «Рекорды» с текстом «Пока нет результатов».
- Кнопка нажимается и ничего на экране не меняет.
- Настроек, поля попытки и секрета нет.
- Просмотр исходника `index.html`: в `body` только `script`.
- Стили подключаются из `css/base.css` и `css/components.css`.

## `feat/settings`

Экран до старта:

- Группа системы счисления из четырёх пунктов: двоичная, восьмеричная, десятичная, шестнадцатеричная. Выбрана десятичная.
- Длина: пункты 2, 3, 4, 5, 6. Выбрана 4. Все доступны.
- Строка «Возможных секретов: 5040». Число берётся из `countPossibleSecrets` и меняется вместе с выбором.
- Кнопка «Начать игру».

Смена системы:

- Двоичная система делает пункты 3–6 недоступными (`disabled`, не скрывать) и выбирает длину 2. Строка секретов показывает `2`.
- Возврат на десятичную снова включает 3–6. Если перед этим была выбрана длина 2, она остаётся 2, пока игрок сам не сменит.
- Восьмеричная, десятичная и шестнадцатеричная оставляют доступными все длины 2–6.

Старт раунда:

- `startRound` с `Math.random` и `Date.now`. Секрет на экран не выводится.
- Пункты длины, системы и кнопка «Начать игру» становятся `disabled`.
- Появляется блок раунда с подписью выбранных условий, например «4 · десятичная». Поля попытки на этом шаге ещё нет.
- Повторно нажать «Начать игру» нельзя, пока настройки заблокированы.
- «Новая игра» на этом шаге по-прежнему может не сбрасывать раунд: сброс делает `feat/new-game`. До этого шага выйти из начатого раунда можно перезагрузкой страницы.

## `feat/guess`

В блоке раунда появляются поле «Попытка», кнопка «Проверить» и история.

Поле:

- `maxLength` равен длине секрета, `autocomplete="off"`, `spellcheck="false"`.
- `createDigitValidator(base)` решает, можно ли вставить символ. Чужой символ не появляется в поле. В hex `A`–`F` вводятся и в верхнем, и в нижнем регистре.
- Вставка из буфера оставляет только допустимые символы и обрезает строку до длины секрета.
- «Проверить» недоступна, пока `isValidGuess` для текущего текста ложен. Enter в поле делает то же, что клик по доступной кнопке.

История:

- До первой попытки виден текст «Пока нет попыток».
- Удачная новая попытка убирает эту фразу и добавляет строку в конец: попытка в нижнем регистре, быки, коровы. Старые строки остаются.
- Повтор (в том числе другим регистром в hex) не добавляет строку. Над полем текст «Эта попытка уже была». Введённый текст в поле остаётся.
- Список строится `createElement` и `textContent`.

На этом шаге победа ещё может не блокировать поле: даже если быков уже столько, сколько длина, отдельный победный блок рисует `feat/win`. История при этом уже содержит верную последнюю строку, потому что её добавляет `applyGuess`.

## `feat/win`

- Над полем идёт время с момента `startedAt`. Раз в секунду текст обновляется через `formatDuration`. Интервал живёт в UI, не в ядре.
- Когда `applyGuess` вернул `status: "won"`:
  - поле и «Проверить» недоступны;
  - интервал снят, на экране замершее `formatDuration(finishedAt - startedAt)`;
  - видны «Вы угадали», «Попыток: N» (длина истории) и «Секрет: …»;
  - ещё одна попытка не добавляется.
- Раунд, брошенный до победы, этого блока не показывает. Запись в рекорды делает следующий шаг, не этот.

## `feat/leaderboard`

Контракт данных: [leaderboard.md](./leaderboard.md). На экране секция таблицы следует ему. Переход в победу пишет результат один раз.

## `feat/new-game`

Кнопка «Новая игра» в шапке:

- снимает интервал времени, если он был;
- прячет блок раунда, очищает историю и статус;
- снова включает настройки и «Начать игру», заново применяет правило двоичной длины;
- не вызывает `location.reload`;
- не удаляет уже лежащие в `localStorage` рекорды;
- до победы ничего в рекорды не дописывает;
- после победы сохранённую строку не дублирует и не стирает.

До первого раунда кнопка остаётся на экране настроек и не показывает ошибку.
