# DESIGN.md

Шаг `docs/design` создаёт `DESIGN.md` в корне `bulls-and-cows`. Писать его раньше нельзя: разделы ссылаются на уже существующие файлы и функции. Если реализация разошлась с ожидаемой сложностью ниже, в документе описывается фактический код, а спека ядра поправляется в том же PR.

## 1. Структуры и алгоритмы

Описать конкретно:

- секрет и попытка — строки в нижнем регистре, почему не число (`0123`);
- `Round` и `Attempt` из [state.md](./state.md), и что новая попытка — это новый массив `[...history, entry]`;
- `evaluateGuess`: множество символов секрета и два прохода `filter`;
- `generateSecret`: Фишер–Йейтс по алфавиту основания;
- `countPossibleSecrets`: рекуррентность `P(base, length)` и ключ кеша.

## 2. Сложность

Для каждой функции — оценка и откуда она берётся. Ожидаемая форма, если код совпадёт со спекой:

| Функция | Время | Почему |
| --- | --- | --- |
| `generateSecret` | `O(base)` | один проход тасовки по алфавиту основания, `base ≤ 16`, плюс срез длины |
| `evaluateGuess` | `O(n)` | `n` — длина секрета; множество за один `reduce`, быки и коровы за два прохода без вложенного поиска |
| `isValidGuess` | `O(n)` | один проход предиката и одна проверка повторов множеством |
| `countPossibleSecrets` | первый вызов `O(length)`, повтор с тем же ключом `O(1)` | рекурсия — одна цепочка глубины `length`, не дерево; кеш снимает повтор при открытии настроек |

Память упомянуть одной фразой: стек рекурсии `O(length)`, кеш растёт по числу разных пар `(length, base)`, история раунда `O(попытки)`.

Рубрика задания просит Big O именно для этих четырёх функций. `createDigitValidator` в список не входит.

## 3. Чистый код

Принципы из модуля Clean Code, каждый с файлом и функцией. Минимум, если код так и написан:

- одно имя — одно действие: `isAllowedSettings`, `applyGuess`, `formatDuration`;
- побочный эффект часов и случайности вынесен в аргумент `now` / `random`;
- ядро не знает про DOM (`src/core` против `src/ui`);
- алфавит цифр не продублирован;
- заглушка и тесты не протекают в реализацию: зелёный коммит не содержит `throw new Error("not implemented")`.

Абзац без указания функции не засчитывать как выполненный пункт.
