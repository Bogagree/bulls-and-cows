# Code conventions

Стек и слои: [architecture.md](../specs/architecture.md). Решения: [decisions.md](../decisions.md).

## TypeScript

- `strict: true`. Сборка `tsc`, модули ES2022, импорты с суффиксом `.js`.
- `src/core/**/*.test.ts` не попадает в `dist/`.
- В ядре нет `any`. В UI `any` тоже не нужен: у элемента конкретный тип HTMLElement.
- Классы в `src/core` запрещены и на ревью, и правилом ESLint `no-restricted-syntax` для `ClassDeclaration`.

## Тесты

- Jest, среда `node`. DOM-тестов нет. Конфиг: [D-012](../decisions.md).
- FIRST: тест не ждёт таймер, не зависит от порядка файлов, не читает `Math.random` и `Date.now`, сам говорит pass/fail через `expect`.
- Случайность и часы входят в функцию аргументом. В тесте аргумент детерминированный.
- Один модуль — один файл тестов рядом с ним.
- Общий кеш `countPossibleSecrets` допустим: результат зависит только от аргументов, порядок тестов его не меняет. Число рекурсивных вызовов не ассертить.

## Ядро

- Функция ядра не читает и не пишет DOM, `localStorage`, сеть.
- История попыток и объект раунда не мутируются. Новый вызов возвращает новый объект, старый остаётся прежним.
- Повторяющийся символ и алфавит не копировать вторым списком цифр. Источник алфавита один, в `create-digit-validator.ts`.
- `evaluateGuess` считает быков и коров через `filter` по массивам из `split("")`. Цикл `for` со счётчиком быков там не писать.
- Цикл внутри локальной копии Фишера–Йейтса допустим.

## HTML и CSS

- Исходный `<body>` содержит только `<script type="module" src="./dist/main.js"></script>`.
- Элементы приложения — через `el()` из `src/dom.ts`. Текст — только `textContent`.
- У поля попытки есть подпись. Кнопка с видимым текстом не нуждается в дублирующем `aria-label`.
- BEM, токены в `css/base.css`, стили подключены из `<head>` относительным путём.

## Запрещено

- Класс в игровой логике.
- `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `document.write`, `DOMParser`, `Range.createContextualFragment`.
- `alert`, `confirm`, `prompt`.
- lodash и пакеты с правилами игры, каррированием или мемоизацией.
- Хранить секрет текущего раунда в `localStorage`.
