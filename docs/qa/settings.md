# QA: settings

Проверено в браузере на `http://localhost:4173/` после `npm run build`.

- Старт: выбраны десятичная система и длина 4, строка «Возможных секретов: 5040», кнопка «Начать игру». Поля попытки нет.
- Двоичная система выбирает длину 2, пункты 3–6 остаются на экране и становятся недоступными, строка показывает «Возможных секретов: 2».
- Возврат на десятичную снова включает 3–6 и оставляет длину 2. Число секретов становится 90. Выбор длины 4 возвращает 5040.
- Восьмеричная при длине 4 показывает 1680, шестнадцатеричная — 43680. Все длины 2–6 доступны.
- «Начать игру» блокирует системы, длины и саму кнопку. Появляется «4 · десятичная». Секрет и поле попытки не появляются.
- Повторный старт недоступен. «Новая игра» раунд не снимает.
- На ширине 360px группы настроек переносятся и остаются читаемыми.
