# QA: win

Проверено в браузере на `http://localhost:4173/` после `npm run build`.

- Сразу после «Начать игру» над полем стоит `0:00`. Текста «Вы угадали» нет.
- Пока раунд не выигран, время идёт от `startedAt`. После неверной попытки история растёт, поле остаётся доступным, победного блока нет. Рекорды остаются «Пока нет результатов».
- В двоичной системе длины 2 попытка `10` дала «10: быки 0, коровы 2» и не завершила раунд. Попытка `01` дала «01: быки 2, коровы 0».
- После победы видны «Вы угадали», «Попыток: 2» и «Секрет: 01». Поле и «Проверить» недоступны. Третья строка в историю не добавляется.
- Время замирает на значении победы: через полторы секунды на экране остаётся тот же текст.
- Записи в рекорды нет.
- На ширине 360px карточка победы остаётся в колонке, горизонтальной прокрутки нет.
