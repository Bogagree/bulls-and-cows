# QA: guess

Проверено в браузере на `http://localhost:4173/` после `npm run build`.

- После «Начать игру» видны подпись условий, поле «Попытка», недоступная «Проверить» и текст «Пока нет попыток».
- У поля `maxLength` равен длине секрета, `autocomplete="off"`, `spellcheck="false"`.
- Символ вне алфавита не остаётся в поле: `g` в десятичной системе не появляется, кнопка остаётся недоступной. Повтор цифры `1123` тоже оставляет «Проверить» недоступной.
- Вставка `12a345` становится `1234` и включает кнопку.
- Enter и клик по «Проверить» добавляют строку и очищают поле. После `1234` и `5678` история: «1234: быки 1, коровы 2», затем «5678: быки 0, коровы 1». Список — `ol` из `li`.
- Повтор `1234` по Enter показывает «Эта попытка уже была», оставляет текст в поле и не добавляет строку.
- В шестнадцатеричной системе длины 2 `gAb` уходит в историю как «ab: быки 2, коровы 0». Повтор `AB` показывает ту же фразу, оставляет `AB` в поле и не добавляет строку.
- Верная попытка не рисует «Вы угадали» и не блокирует поле.
- «Новая игра» по-прежнему без обработчика. `index.html` в `body` содержит только модульный скрипт.
- На ширине 360px поле и кнопка стоят в одной строке карточки, горизонтальной прокрутки нет.
