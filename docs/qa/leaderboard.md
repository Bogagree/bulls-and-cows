# QA: leaderboard

Проверено в браузере на `http://localhost:4173/` после `npm run build`.

- До победы секция показывает «Пока нет результатов». Неверная попытка строку не добавляет.
- Двоичная победа с первой попытки пишет одну запись: место 1, попытки 1, время `0:03`, условия «2 · двоичная». В `localStorage` ключ `bulls-and-cows-results`, секрета в записи нет. Повторный клик по «Проверить» вторую запись не пишет.
- После перезагрузки игрок снова на настройках, поля попытки и секрета нет, та же строка на месте.
- Вторая победа за 2 попытки встаёт ниже: сначала 1 попытка и `0:03`, затем 2 попытки и `0:00`.
- Двенадцать сохранённых результатов после перезагрузки показывают 10 строк, с 1 по 10 попыток, условия «6 · шестнадцатеричная».
- На ширине 360px таблица не вызывает горизонтальную прокрутку страницы.
