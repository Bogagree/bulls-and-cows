# QA — отчёты шагов

Отчёт шага с экраном: `docs/qa/<step>.md`. Имя файла — имя шага без префикса: `feat/guess` → `docs/qa/guess.md`. В отчёте вердикт и что именно проверили. Скриншоты в git не класть.

Для шагов без экрана (`docs/sdd-skeleton`, `chore/tooling`, `chore/husky`, функции ядра, `docs/design`) отчёт не нужен. Их проверка — `npm test`, `npm run lint` и чтение диффа.

Минимум для шага с экраном:

- сценарий из спеки этого шага проходит в браузере кликами, не одним скриншотом;
- соседний уже сделанный сценарий не сломан;
- в исходном `<body>` по-прежнему только `script`;
- в коде шага нет `innerHTML`, `insertAdjacentHTML`, `DOMParser`, `alert`, `confirm`, `prompt`.

Страницу открывать после `npm run build` через локальный статический сервер. Модули с `file://` не проверять.

Перед сдачей отдельно пройти край из [ui.md](../specs/ui.md) и [leaderboard.md](../specs/leaderboard.md): двоичная длина, hex в верхнем регистре, повтор попытки, победа с попытками и временем, перезагрузка сохраняет рекорд и забывает секрет, «Новая игра» посреди раунда не пишет рекорд.
